Models

Every AI step goes to an OpenAI-compatible endpoint you choose: a cloud provider or a model on your own server. A self-hosted model is just another endpoint. Each action asks for a role, and each role points to an endpoint, so moving work to another model needs no code.

What leaves the building

Prompts and context go to the endpoint each role points to, for every AI step, including the code review in the check runner.

Pasted text and uploaded documents are sent marked as data, never as instructions. The AI has no tools with consequences: no git, no releases, no file system.

Who can change this

Admins only. Changing the model provider or a role's endpoint needs your passkey and goes in the audit log.

Later · shadow runs

For chosen actions, another model runs on the same input in the background, and its validity and keep rate are compared before switching.
