Paths and subdomains

Rollback

A rollback is a new release with a higher number that points to an older package, approved with your passkey. Production keeps the last [n] releases on disk, so it switches instantly. Nothing is rebuilt.

Automatic switch back

If the smoke test fails right after a deploy, production switches back to the previous release by itself, without a new signature, and reports it in the outbox. The app then emails every Admin.

Release numbers only decide which new bundles production accepts: always higher than before, so an old bundle can’t be replayed.

Release log

Every release is a commit in the built-in release log with release.json and trailers. Packages are kept forever.
