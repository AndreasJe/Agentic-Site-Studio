Languages

Which languages a site is published in. Off by default: a site has one language until you add another. This is about the sites, not the app; each person picks EN or DA for the app itself.

Addresses

Each language lives under its own subpath, so every version has a link you can share that works without JavaScript. Visitors switch with a language switcher in the header.

No search engine setup

There is no hreflang, no metadata per language and no sitemap per language. Languages are for visitors, not for search engines.

Translated checkmark

In review mode, Translated means every section has copy in every language. It checks completeness only, not the quality of the translation.

No AI work here. The AI can draft copy in each language; a person ticks Translated.
