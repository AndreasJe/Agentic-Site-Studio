When this changes

Existing briefs are migrated to the new setup, for example when a block is removed from the template.
Blocks left empty become “Not set yet.” and an open question. Open questions never block.
Briefs can still be exported as Markdown in the same format.

Section checklist

Seven checkmarks per section, ticked by a person in review mode. Status is derived: In development n/7, or Approved.

1CopyText final, sourced from the brief.
2MediaImages match the subject; restricted images only where allowed.
3InteractionsOnly when the interaction check has no open questions.
4MobileOnly when a mobile version exists.
5MotionStates, durations, easing, reduced motion; poster fallback for 3D.
6TranslatedEnglish and Danish.
7TestedClicked through in the preview on desktop and mobile.
