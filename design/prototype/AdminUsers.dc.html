Recovery codes and machine tokens

Recovery codes

Shown once when a passkey is registered. Keep them in the password manager.

A recovery code only signs an Admin in to register a new passkey, and another Admin must approve that key. It can never approve anything.

With only one Admin, a recovery code gives one person full access again, so keep the codes as carefully as the passkey itself.
